database 1. Data Collection

When you use GeotaggingPhotos, we collect certain information to provide and improve our services. This includes explicitly provided EXIF data, temporary photo uploads, and anonymized usage metrics.

We do not store your original high-resolution photos permanently. They are processed in-memory or stored temporarily on secure servers solely for the duration of the geotagging operation.

  • Device information (OS, browser type)
  • IP address for regional localization
  • Uploaded image EXIF metadata (read-only until modified by user)

location_on 2. Location Services

Our core functionality relies on processing location data. By using our map interface or inputting coordinates, you consent to the processing of geographic data.

Coordinate Input Policy

Data entered via manual coordinate fields (e.g., Lat: 40.7128, Lng: -74.0060) is processed locally where possible, prioritizing user privacy.
